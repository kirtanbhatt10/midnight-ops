# Security Policy

## Scope of this project
midnight-ops ships **documentation and methodology** (Markdown checklists, templates, and a
skill definition). It contains no runtime service, no network code, and no executable
exploit content.

## Reporting a concern
If you believe something in this repository:
- leaks real engagement data, a secret, or client information, or
- could reasonably be read as operational attack content that violates the project's
  authorization-first purpose,

please open a **private** report rather than a public issue:
- Use GitHub's **"Report a vulnerability"** (Security → Advisories) on this repository, or
- contact the maintainers listed in the repository profile.

Please include the file, the specific lines, and why it's a concern. We aim to acknowledge
within a few business days.

## Responsible use
This project is for **authorized** security testing, education, and defensive research only.
Unauthorized access to computer systems is illegal in most jurisdictions. Users are solely
responsible for obtaining written authorization and complying with applicable law.
